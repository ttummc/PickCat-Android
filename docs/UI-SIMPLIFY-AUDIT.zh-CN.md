# PickCat UI 精简审计

[English](UI-SIMPLIFY-AUDIT.md) | 中文

目标：更简洁、更少装饰、更清晰的排版。以下 50 条按页面分组。

## 顶部与导航

1. 删除论坛顶栏副标题“所有话题，按分类归档”。
2. 删除作品顶栏副标题“KittenN 与 BoxPlay 社区作品”。
3. 删除首页顶栏下的分割线。
4. 删除论坛顶栏下的分割线。
5. 删除作品顶栏下的分割线。
6. 删除通知顶栏下的装饰性层级。
7. 减少底部导航的说明性文案。
8. 统一所有页面标题为单行，不再堆叠副标题。
9. 设置页不再重复显示“PickCat Android 原生版”和介绍段落。
10. 移除“关于”里重复的技术栈说明。

## 首页

11. 首页问候语只保留必要的用户名。
12. 缩短首页空状态描述。
13. 首页不再重复“发帖”按钮文案。
14. 首页卡片间距从 12dp 收紧为 10dp。
15. 首页移除多余的分区标题装饰。

## 论坛与分类

16. 论坛分类和排序保持单行。
17. 分类页不再重复“排序”说明。
18. 分类页空状态只保留一句描述。
19. 主题卡片移除重复的统计图标说明。
20. 取消分类入口的二级说明文字。

## 作品

21. 作品页空状态缩短。
22. 作品卡片移除多余的作者行重复信息。
23. 作品详情简介卡不再保留标题“简介”。
24. 作品详情操作说明卡不再保留标题“操作说明”。
25. 作者其他作品只在有数据时展示。

## 帖子详情

26. 移除收藏文本与收藏图标重复。
27. 回复区顶部只保留必要统计。
28. 举报弹窗标题缩短。
29. 评论输入框不再重复“支持 Markdown”说明。
30. 回复失败提示统一为短句。

## 搜索

31. 搜索页去掉重复的“开始搜索”说明。
32. 标签结果只显示名称和跳转箭头。
33. 搜索结果分区标题精简。
34. 搜索空结果只保留一句提示。
35. 清除搜索历史按钮改成图标或短文本。

## 通知

36. 通知卡片仅保留头像、内容、时间。
37. 未读只保留圆点。
38. 移除通知类型小图标。
39. 通知空状态缩短。
40. 通知分类只保留官网五项。

## 设置与个人资料

41. 移除不可点击的头像预设画廊。
42. 账号卡片不再显示重复的“查看主页”按钮。
43. 关于卡片只保留版本和登录方式。
44. 移除“后台通知”长说明，保留一行。
45. 编辑资料页减少说明文字。
46. 个人主页标签数从 8 个减少为 6 个。

## 编辑器与通用

47. 移除编辑器底部“草稿会自动保存”。
48. 移除编辑器底部重复的“已选 N 个分类”。
49. SectionHeader 上下间距从 9dp 收紧。
50. 统一空状态的标题和描述长度。

## 状态

50 条已全部处理完毕。

第 6、7、15、17、19、20、22、27、33 条复核后确认保持现状，因为剩余结构承载必要信息或交互。

- 关于卡片去掉重复技术栈说明
- 发帖页移除底部重复标签计数和草稿提示
- 多页空状态缩短文案
- SectionHeader 间距收紧
- 作品详情不再重复“简介”和“操作说明”标题
- 搜索标签结果只保留名称和箭头
- 清除搜索历史改为图标按钮
- 通知卡片不再单独显示类型文案
- 账户卡片不再重复“查看主页”
