# PickCat Android UI 审计

记录 50 处可优化点。最终状态：39 条修改完成，11 条复核后确认保持现状。

## 动效

1. 首页、论坛和媒体库的 FloatingActionButton 不随滚动隐藏，遮挡内容。已修复。
2. NavHost 对底部标签切换和详情页跳转使用同一套位移，缺少 Material 3 的层级区分。已改为淡入缩放过渡。
3. 启动页、登录页、主界面之间的切换仍是硬切。已加入根级淡入淡出。
4. 通知列表从骨架屏进入内容时没有淡入过渡。已修复。
5. 搜索页的历史记录、结果列表切换过于生硬。已加入状态淡入。
6. 媒体库 READY/UPLOADING 标签内容切换没有过渡。已修复。
7. 个人页精选、话题、作品标签内容切换没有淡入。已加入 item 淡入与位移动画。
8. 发帖页编辑与预览之间是瞬时替换。已修复。
9. 通知行动画缺失，已读操作后列表跳变。已加入 item 动画。
10. 收到的赞列表缺少 item 动画。已修复。
11. 搜索结果缺少 item 动画。已修复。
12. 媒体网格缺少新增或删除时的位移动画。已修复。

## 视觉层级

13. 个人页头图文字缺少稳定的对比度保护。复核：文字位于头图下方，不直接叠图，保持现状。
14. 各页 SectionHeader 与副标题的组合不一致。复核：页面标题与 SectionHeader 承担不同层级，保持现状。
15. 作品类型角标对比度偏低。已改为 secondaryContainer 与 onSecondaryContainer。
16. SearchBar 容器色与页面卡片色不统一。已统一为 surfaceContainerLow。
17. 论坛“浏览分类”按钮仍偏表单感。已改为 FilledTonalButton。
18. 发帖工具栏图标密度和间距不均。已改为横向可滚动工具条并统一底色。
19. 个人页数据面板分隔线偏重。已减淡并放大数字层级。
20. 长用户名在通知和评论中的截断策略不一致。已统一为单行省略。
21. 帖子详情头部元信息过密。已改为可换行 FlowRow。
22. 作品详情标签、作者、统计信息分组不够清楚。已在统计与操作按钮之间加入分隔。
23. 空状态图标重复，缺少页面语义。个人页已按动态、帖子、作品、回复、关注补充专用图标。
24. 设置页危险操作没有足够的视觉区分。退出按钮已使用 onErrorContainer 色彩。
25. FAB 尺寸和内容区块比例不一致。复核：使用标准 ExtendedFloatingActionButton，保持现状。
26. 普通内容卡片层级几乎相同，重点内容不突出。复核：层级由标题、留白和置顶标签表达，保持现状。
27. 评论线程竖线颜色偏重。已降低透明度。
28. 举报弹窗内容较长时缺少滚动容器。已加入限高滚动。

## 布局与安全区

29. 发帖页底部按钮与输入法、手势条的组合间距需复核。复核：外层导航 inset 与 imePadding 已覆盖，保持现状。
30. 通知页底部内容留白不足。已增加底部留白。
31. 论坛分类和排序一行在小屏上过于拥挤。已收窄排序控件宽度。
32. 分类页与论坛页顶部控件对齐方式不同。复核：分类页保留“排序”标签，论坛页保留分类入口，保持现状。
33. 个人页头图固定比例，宽屏下裁切过多。复核：156dp 头图在手机与宽屏均可接受，保持现状。
34. 大屏只有作品页使用双栏，论坛和帖子详情仍是单栏。论坛和作品使用双栏，独立帖子页保留限宽单栏。
35. 论坛在平板上缺少列表和详情的并列布局。已加入论坛双栏。
36. 帖子详情在平板上最大宽度没有限制。已限制为 860dp，作品详情同步处理。
37. 搜索页结果顶部与搜索栏的间距偏紧。已调整顶部间距。
38. 媒体网格说明文字容易被截断。时间文本已加入权重和省略。
39. 评论输入框埋在列表末尾，回复长帖时难以触达。已增加回复 FAB 并动画滚动到底部。
40. 无网络横幅可能覆盖 FAB 或 Snackbar。已上移到 FAB 上方。

## 交互与可达性

41. 重复点击当前底部标签不会回到顶部。已加入 reselect 信号和动画回顶。
42. 首页按返回键直接退出应用。已加入再次返回才退出的提示。
43. 未读圆点没有无障碍语义。已补充“未读”描述。
44. 通知页返回后滚动位置需要确认。已接入 LazyListState 保存位置。
45. 下拉刷新没有轻触反馈。首页、论坛、作品已加入触觉反馈。
46. 点赞、收藏状态切换缺少轻微缩放或颜色过渡。已加入图标淡入淡出。
47. 收藏按钮图标切换没有动画。已加入图标淡入淡出。
48. 长按操作不可发现。复核：当前没有必须隐藏的长按功能，保持现状。
49. 发帖页输入焦点顺序需要验证。复核：顺序为标题、分类、正文、发布，保持现状。
50. 部分图标按钮缺少 contentDescription。复核：图标按钮均有描述或由可见文本承载语义。
