# PickCat Android v0.1.72

## 新增

- 帖子正文中的链接现在可以点击，不需要再长按选中后走系统菜单。
- `https://pickcat.dao3.fun` 的帖子、用户主页和作品链接会直接在 PickCat 内打开对应页面。
- 其他站点链接仍交给系统浏览器处理。

## 关于系统长按菜单的“打开”

- 长按选中链接时显示的“打开”由系统决定交给哪个已注册应用。
- 当浏览器被设为所有 https 链接的默认应用时，系统会直接使用浏览器，不会弹出选择器。
- 如需让 PickCat 出现在该菜单中，可在系统设置中为 PickCat 开启“打开支持的链接”，或清除浏览器的默认打开设置后重新选择。
- 现在应用内直接点击链接即可在 PickCat 中打开，不再依赖该系统菜单。
