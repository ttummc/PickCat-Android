# PickCat Android v0.1.71

## 新增

- 支持用 PickCat 打开 PickCat 官方链接。
- 在任意应用中选中或点击 `https://pickcat.dao3.fun` 链接时，系统选择器会出现 PickCat。
- 已支持的链接：
  - 帖子 `https://pickcat.dao3.fun/forum/post/...`，带 `#post-N` 时定位到对应楼层
  - 用户主页 `https://pickcat.dao3.fun/profile/...`
  - 作品 `https://pickcat.dao3.fun/works/...`
  - 论坛、作品、设置、通知页
- 应用未登录时会先完成登录，登录后自动跳转到链接对应页面。

## 说明

- 由于该域名由 PickCat 官方维护，未配置数字资产链接验证，首次打开时系统可能询问使用哪个应用，选择合适的应用后即可设为默认。
