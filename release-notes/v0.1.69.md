# PickCat Android v0.1.69

## CodeChat

- 按最新 API 文档重新实现 CodeChat，不再沿用旧版连接与消息逻辑。
- 支持 PickCat 身份登录与自动注册、令牌校验、权限读取。
- 支持 WebSocket 在线状态、心跳、断线重连、pcAssertion 校验。
- 支持公共群聊与私聊会话列表、消息历史、未读状态、图片发送、引用、撤回和举报。
- 保留首次使用第三方服务确认、默认关闭和访问密码 67。
- 保留个人主页的 CodeChat 私聊入口与导航未读角标。

## 账号

- 修复添加第二个账号后原账号被 401 过期清理误删的问题。添加或切换账号期间暂停自动过期清理。

## 设置

- 设置页使用简洁的 Material 3 布局，并保留搜索过滤。
- CodeChat 开关重新加入访问密码确认。

## 发布

- GitHub Release 改为正式 `assembleRelease` 构建，不再上传 debug APK。
- 发行说明改为随版本提交的中文文件。
