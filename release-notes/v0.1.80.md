# PickCat Android v0.1.80

## 设置页

- 设置页按主流应用版式重排：顶部搜索框、账号卡片、分组设置卡片、底部弱化退出入口。
- 账号卡片展示头像、昵称、邮箱、等级与猫币，点击直接打开账号切换面板。
- 等级进度改为卡片内展示，能力、责任、关怀三个指标分行排列。
- 搜索框支持一键清除，搜索结果为空时给出提示。
- 各分组改为独立卡片容器，行内分割线缩进对齐，间距统一。
- 版本信息与非官方客户端说明合并到页面底部居中展示。

## 个人主页

- 手机版个人主页改为封面加头像的资料头布局，头像置于封面下沿。
- 昵称使用大标题层级，等级与徽章标签排在昵称下方。
- 地区与加入时间分行展示，粉丝、关注、帖子、回复改为四列统计。
- 本人主页隐藏顶部标题栏，设置与更多入口位于资料区右侧。
- 他人主页保留顶部返回栏，关注按钮置于资料区右侧。
- 标签栏改为吸顶显示，滚动浏览内容时仍可切换分区。

## 说明

- 本次只调整界面结构，账号、设置、关注、分页等逻辑未改变。
- 已移除 CodeChat 相关残留，界面不再出现相关入口。
